Monte seu leilão

Escale os jogadores, escolha os temas e defina as regras. Os itens são sorteados e revelados um a um — estratégia, timing e um bom martelo decidem quem monta o melhor time.

Modo de jogo

Jogadores

Toque em um nome para escalar (de 2 a 6). Os nomes ficam salvos para as próximas partidas.

Sala

O modo sala precisa do servidor do jogo rodando neste computador. Dê dois cliques em Iniciar Leilão.command (Mac) ou Iniciar Leilao.bat (Windows) na pasta do jogo — ou, no terminal:

npm install
npm start

Depois abra http://localhost:3000 e tente de novo. Não tem o jogo baixado? github.com/kayocalabria/Auction

Sem computador por perto? Em um celular Android dá para rodar o servidor direto nele, via Termux — veja o passo a passo no README do projeto. (Não funciona em iPhone.)

Gere um código e peça para cada um abrir o endereço no celular.

Quem já entrou

Ninguém consegue entrar?
  • Todos precisam estar no mesmo Wi-Fi deste computador (não use dados móveis).
  • Se o Mac perguntou se o node pode aceitar conexões, precisa permitir (Ajustes → Rede → Firewall).
  • Redes de hotel, empresa ou "convidados" isolam os aparelhos entre si — use o hotspot de um celular e conecte o computador nele.
  • Se aparecerem dois endereços no terminal, tente o outro.

Regras da partida
